# 液态玻璃设置主题（liquid-glass）

给 Digital Clock 的**设置窗口**换一套苹果 Liquid Glass 风格的皮肤 + 布局。

## 装法

1. 打开时钟托盘菜单 → 设置 → 左侧「插件」；
2. 点「📦 导入插件…」，选 `liquid-glass.dcplugin`（或同内容的 `.zip`）；
3. 导入后插件默认**不启用**？—— 在我们这里导入即落盘，回到插件列表把它的开关打开即可；
4. 打开后会多出一条导航「🫧 玻璃主题」，所有开关都在那一页里。

停用插件（插件卡片上的开关）即可完全恢复原样：所有改动都是登记过的，卸载时逐项还原。

## 这插件改了什么

| 层 | 做法 |
|---|---|
| 背景 | 四团彩色光斑（极光）缓慢漂移 + 一层极淡噪点，`z-index:-1` 铺在界面之下 |
| 外壳 | 自绘标题栏、左侧栏、右侧内容区三块独立玻璃面板（`backdrop-filter: blur() saturate()`） |
| 导航 | 导航项改成药丸；选中态是一块**会滑动的玻璃滑块**（弹簧缓动，位置由 JS 跟着实时的 active 项算） |
| 布局 | 三种模式：卡片分组（单列玻璃卡）/ 双列网格（窄窗口自动回落单列）/ 经典单列 |
| 控件 | 开关 iOS 化（弹簧位移）、滑条细轨 + 白色玻璃圆钮、下拉与输入框玻璃化、按钮带内高光 |
| 配色 | 深色玻璃 / 浅色玻璃 / 跟随昼夜（7:00–19:00 浅色），只换一组 `--lg-*` 变量 |
| 可选 | 液态折射（SVG `feTurbulence` → `feDisplacementMap` 位移背景）、颗粒质感、隐藏滚动条 |

## 设置项（15 项，全部即时预览 + 显式保存）

布局方式 / 圆角大小 / 药丸滑块指示器 / 玻璃模糊 / 玻璃通透度 / 高光强度 / 强调色辉光 /
配色模式 / 强调色 / 极光流光动效 / 流光周期 / 颗粒质感 / 液态折射 / 折射强度 / 隐藏滚动条

改动只进本地草稿（外观即时变化），点「保存并应用」才写回设置。宿主每写一项设置就会重载插件，
所以这里刻意做成「攒够了一次性提交」，并在重载后自动切回本页。

## 已知限制

- **只在设置窗口生效**（`settings.theme` 钩子），时钟窗口与关灯窗口不受影响。
- 设置窗口是自绘标题栏（`frame:false`，宿主 v1.0.5.5 起）→ 这套主题连标题栏一起接管；原本生硬的 Windows 原生标题栏已经不存在了。
- **液态折射**用 SVG 滤镜，`backdrop-filter` + `filter: url()` 叠加吃 GPU；默认关闭，卡就先关它。
- 双列网格里带滑条 / 色块 / 多列控件的行会自动横跨整行（否则会被挤扁），这是有意为之。
- 「跟随昼夜」用本地时间 7:00 / 19:00 分界，每分钟检查一次，跨点时自动换。
- 草稿预览**跨页保留**：改完设置翻到别的页也能看到效果，离开插件页时会提示一次「有未保存的改动」。

## 开发

- 源码在仓库 `examples/liquid-glass/`，不进安装包。
- 静态校验：`node .plugin-probe/validate.js`
- 渲染探针（真实设置窗口 + 假 electronAPI，跑完出截图与断言）：
  `env -u ELECTRON_RUN_AS_NODE -u NODE_OPTIONS node_modules/electron/dist/electron.exe .plugin-probe --no-sandbox --disable-gpu`
- 打包：`node .plugin-probe/build-zip.js`
