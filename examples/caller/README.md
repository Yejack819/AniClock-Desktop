# 远程喊人提醒 · ClassCaller（Digital Clock 插件）

把班级「远程喊人」搬上 Digital Clock：老师在办公室用手机发消息后，教室的时钟也会跟着提醒——

- **日期栏**：出现 `📢 张老师+1`（可改为红点 / 人数 / 关闭），新来电闪烁提示
- **关灯全屏**：开启关灯模式时，来电以毛玻璃大卡片呈现（学科 + 老师 + 被点名的同学 + 留言 + 倒计时），叮咚一声，点「知道了」或等大屏倒计时结束自动消失
- **设置页**：左侧导航多一页「📢 远程喊人」——连接状态、当前在屏、来电记录、一键测试

## 数据从哪来

插件是 ClassCaller 的一个**只读观察端**，两条通道任选：

| 通道 | 适用 | 填什么 |
|---|---|---|
| 云端 MQTT（推荐） | 时钟和教室电脑不在同一网络 | ClassCaller 设置页「云端中转」里的**云端 ID**（班级码） |
| 本机服务 | 时钟与教室电脑同网（或就是同一台电脑） | `ws://<教室电脑IP>:9527/ws`，默认 `ws://127.0.0.1:9527/ws` |

## 使用步骤

1. ClassCaller（教室电脑）里打开云端中转并记下云端 ID，或确认本机服务端口（默认 9527）
2. Digital Clock → 设置 → 插件 → 导入本目录打包出的 `.dcplugin`
3. 在插件设置里选通道、填班级码 / 本机地址
4. 点导航页的「🔔 测试提醒」验证全链路

## 说明与边界

- 插件**只接收**：不能替你在教室大屏上点「我知道了」，时钟上的按钮只是关掉时钟这一侧的提醒
- MQTT 走公共 Broker（与 ClassCaller 预设一致，可自行填写地址），QoS0 尽力送达，插件离线期间的来电靠 retain 快照与重连补齐，极短瞬间的广播可能错过
- 信息栏文字会撑宽时钟窗口（宿主按信息栏宽度算窗口宽度），「老师名」模式已尽量精简，介意可改「红点」模式
- `时钟上也响` 默认关闭：关灯未开时新来电只闪日期栏，不响铃
