# 秒表 · 关灯背景板 + 日期条 + 设置页（stopwatch）

Digital Clock 的外部插件：**一个秒表，三处入口** ——

- **关灯背景板**上的大卡片：5 种样式、九宫格定位、昼夜自动配色
- **时钟窗口日期栏**里的紧凑秒表：3 种样式，跟日期 / 星期 / 时区同一行
- **设置窗口左侧导航**里的「秒表」页：实时状态 + 常用操作 + 全部设置项

三处共享**同一份计时状态**：在任意一处按了开始，另外两处看到的都是同一个时间。

- 插件 id：`com.yejack819.stopwatch`
- 钩子：`lightsOff.background`、`clock.infoBar`、`settings.theme`
- 权限：`storage`（记住计时状态 + 跨窗口同步）、`ui.settings`（在设置窗口开自己的导航页）
- API：`apiVersion: 2`
- 版本：1.1.2 ｜ 作者：Yejack819

## 安装

设置 → **插件** → 导入插件… 选 `stopwatch.dcplugin`（或直接把 `stopwatch` 文件夹用「导入文件夹…」选中，开发时迭代最快）。同 id 再导入会询问覆盖，已有设置值保留。

首次启用会列两条权限让你确认：`storage`（记住计时状态、跨窗口同步）和 `ui.settings`（在设置窗口开自己的导航页）。

## 控制方式

| 按键 | 作用 |
|---|---|
| `空格` | 开始 / 暂停（暂停不清零） |
| `L` | 计次（记录累计时间，自动算每圈分段） |
| `R` | 重置（时间 + 计次一起清零） |
| `C` | 清空计次（保留正在走的时间） |
| `ESC` | 退出关灯（宿主功能，与插件互不干扰） |

键盘在两个窗口都可用。鼠标另有两套：

**关灯窗口** —— 秒表层默认**完全不吃鼠标事件**，这是刻意的：只有这样才能保证「双击背景退出关灯 / ESC 退出」在任何情况下都有效。打开「鼠标控制按钮」后，秒表下方浮出一排迷你按钮，**只有这一小块接收指针事件**，按钮上挂了 `stopPropagation`，双击按钮不会误触退出。

**日期条** —— 三种手势：单击 = 开始/暂停、双击 = 计次、**长按 0.7 秒 = 重置**（按下即有按压反馈，触发时数字脉冲一次；按住过程中移动超过 6px 视为拖动，整个手势取消）。`.clock` 整块是 `-webkit-app-region: drag`，所以插槽自己设了 `no-drag` 才点得动；关掉「日期条可点击控制」后，那块区域会恢复成可拖动窗口。注意单击有约 **0.24 秒**判定延迟（要等一等看是不是双击），而长按会一路按到 0.7 秒才触发。

**设置页** —— 设置窗口左侧导航里的「秒表」页有四个按钮（开始/暂停 · 计次 · 重置 · 清空计次），在那里也能控制秒表，不用切回时钟窗口。

## 设置窗口里的「秒表」页

设置 → 左侧导航 **「秒表」**（位置在「插件」项之后，与内置项同款样式）。

- **实时状态**：当前计时（每秒刷新）、运行 / 暂停 / 待开始、圈数。三处共享同一份状态，这里看到的就是关灯背景板上那个表。
- **常用操作**：开始/暂停、计次、重置、清空计次。
- **全部设置项**：22 项，按「关灯背景板 / 显示 / 操作 / 数据与目标 / 日期条」五组排布，控件直接复用宿主的设置行结构，外观与内置设置一致。

**改完要点「保存并应用」，这是宿主机制决定的。** 插件的设置值归宿主管：
`dc.settings` 是 `Object.freeze` 的只读副本，写回只能走 preload 的 `setPluginSetting(id, key, value)`，
而它每写一次就 `broadcastPlugins()` → 插件整体重载。所以这一页用「草稿 + 显式保存」：

| 行为 | 说明 |
|---|---|
| 拖动滑条 / 改下拉 | 只更新页面里的**草稿**（数值即时预览），不写宿主 —— 所以拖滑条不会卡 |
| 底部提示 | 「有 N 项改动未保存」，保存按钮同时点亮 |
| **保存并应用** | 一次性提交**有改动的项**（改 5 项也只重载一次），保存后插件重载，页面自动切回本页 |
| **放弃修改** | 界面恢复成宿主当前的值，不写任何东西 |

> 设置项在「插件」页的卡片里也有一份（宿主自动渲染的），那边是改一项立刻生效 —— 两处都能改，值始终是同一份。

## 设置项（20 项）

| 分组 | 项 |
|---|---|
| 关灯外观 | 样式 · 位置（九宫格） · 边距 · 缩放 · 整体不透明度 · 卡片底色 · 强调色 |
| 通用显示 | 时间格式（`MM:SS.mm` / `HH:MM:SS`） · 冒号闪烁 · 显示操作提示 · 显示计次列表 |
| 操作 | 键盘快捷键 · 鼠标控制按钮 · 进入关灯自动开始 |
| 数据 | 记住计时状态 · 目标时长提醒 + 目标分钟数 |
| 日期条 | 日期条样式（状态点 / 纯文字 / 胶囊 / 不显示） · 打开关灯时自动隐藏 · 日期条显示百分秒 · 日期条字号 · 日期条可点击控制 |

上面这 22 项在**设置窗口左侧的「秒表」页里也能改**（草稿 + 保存），那页另外还有实时状态与四个操作按钮。

## 样式

**关灯 5 种**：经典（状态灯 + 大数字 + 副信息）· 极简（只留数字）· 圆环（外圈 60 秒转一圈）· 计次板（数字 + 分组成绩）· 数码管（强调色发光方字）。

**日期条 3 种**：状态点 + 时间 · 纯文字（只有时间，最窄）· 胶囊（带底色衬托）。另有「**不显示**」—— 会把插槽整个摘掉，日期栏不会因为插件留下空白，秒表此后只在关灯背景板上出现（这就是「手动关掉日期栏」的办法）。

**不想两处同时显示**：`main.js` 在进入关灯时会强制 `show()` 时钟窗口（「关灯时为了显示时钟曾强制 show」），所以日期栏的秒表会跟着露出来。开着「**打开关灯时自动隐藏日期栏**」（默认开）就会在进入关灯时先把它收起来，退出关灯后自动恢复 —— 靠宿主 preload 的 `onLightsOffStateChanged` 事件驱动，挂载时再用 `getConfig().lightsOff` 取一次初值。

## 实现要点

- **计时内核用 `performance.now()` 单调时钟**，暂停不清零、不受系统时间被手动改动的影响；每帧按公式重算 elapsed，掉帧或窗口被遮挡都不会累积误差。暂停时 `requestAnimationFrame` 直接停掉，不空转。
- **跨窗口共享一份状态**：时钟窗口与关灯窗口是两个渲染进程，`dc.on/emit` 只在进程内，所以同步走 storage —— 统一 key `state` + `rev` 版本号。状态变更时 `rev++` 写入，运行中每 5 秒保活写入（`rev` 不变，避免另一窗口无谓重载），每个窗口每 1 秒读一次、只有 `rev` 变大才应用。计时是「墙钟外推」的确定性计算，所以两边数字天然一致。
- **持久化**：落盘时除了累计毫秒，还记一个墙钟时刻；恢复时如果记录里是「运行中」，按现实时间把间隔补齐（上限 7 天，防墙钟跳变）。退出关灯、重启应用，秒表接着走。v1.0.0 用的带屏幕签名的旧 key 会在首次挂载时自动迁移过来。
- **关灯状态靠宿主事件**：`onLightsOffStateChanged` 没有对应的取消订阅方法，而插件改一次设置就会重挂载一次 —— 所以用一个挂在 `window` 上的自增令牌让旧实例的回调直接失效，避免旧闭包去改已经不在 DOM 里的插槽。
- **设置页为什么不「改一项立刻生效」**：插件的设置值归宿主管（`dc.settings` 只读），写回只能走 `setPluginSetting`，而它每写一次就广播并让插件整体重载 —— 拖一下滑条就重建一次页面根本没法用。所以那页改成「草稿 + 显式保存」，只提交有改动的项。
- **重载后自动切回本页**：插件重载时导航页整块重建，宿主 `refreshNavItems()` 发现当前面板从 DOM 消失就把人退回「插件」页。所以用一个挂在 `window` 上的 `__swOnMyPage` 记住「用户上次停在我的页」，重挂载时自己点回来 —— 否则改完设置就得重新点一次导航。
- **设置项的元数据不重抄**：那页的 22 项是从宿主 `plugin-list` 返回的清单里读的（`settings` 带 key/type/label/hint/min/max/options/default），插件里不留第二份定义，就不会出现两处不一致。
- **键盘只在关灯 / 时钟窗口生效**：设置窗口里空格与字母键要留给输入框和导航。
- **日期条不改窗口尺寸**：时钟窗口宽度 = `max(数字区, 信息栏)`，所以日期条上的秒表只在**文本长度真的变化时**（例如 `99:59` → `100:00`）才派发一次 `dc-plugins-updated` 让宿主重算，绝不每帧调 `setInfoText`（那会每秒触发几十次 `resizeWindow`）。
- **尺寸全部用 `em`**：关灯卡片把基准字号写在卡片上（一个「缩放」滑条整体缩放）；日期条则完全继承 `#info-bar` 的字号 / 字体 / 颜色，自动跟随时钟字号与昼夜配色。
- 关灯卡片配色由 `dc.theme().isDark` 决定，跟随背景板实际明暗自动换深卡 / 浅卡。

## 已知边界

- 关灯锁定（右下角 🔒）状态下 `ESC` 不再退出，此时若又关掉了鼠标控制，只剩右下角「退出」按钮 —— 这是宿主既有行为，不是插件的 bug。
- 秒表不提供分圈导出／历史记录，只保留最近 4 圈的可视列表（数据里最多留 200 圈）。
- 「进入关灯自动开始」只在**关灯窗口**、且**没有历史记录**时触发，不会覆盖上一次的成绩。
- 多显示器下每块屏各有一个关灯窗口，它们和时钟窗口共享同一个秒表（同一份状态）。
- 如果把时钟字号调得很小又打开「日期条显示百分秒」，日期栏可能比数字区更宽、从而把时钟窗口撑宽一些 —— 关掉该项即可收窄。
