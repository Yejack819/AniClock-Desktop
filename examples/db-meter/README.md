# 分贝仪 · 关灯背景板 + 设置窗口导航页（db-meter）

Digital Clock 的外部插件。关灯后在全屏背景板上浮出一个实时分贝仪表；设置窗口左侧导航里另有一页「分贝仪」，带实时预览与一键校准。

- **插件 id**：`com.yejack819.dbmeter`
- **钩子**：`lightsOff.background`（背景板仪表）、`settings.theme`（导航页）
- **权限**：`ui.settings`（在设置窗口开一页导航）—— 不读写插件数据、不联网
- **API 版本**：2

## 安装

设置 → 插件 → **导入插件…** 选中 `.dcplugin`（本质是 zip），或解压后用 **导入文件夹…**。
导入后立即启用：进入关灯即可看到仪表，设置窗口左侧导航会多出「🔊 分贝仪」一页。

## 两个入口

| 入口 | 位置 | 能做什么 |
|---|---|---|
| 背景板仪表 | 关灯模式的背景板 | 9 种样式、九宫格定位、缩放 / 不透明度、昼夜自动配色 |
| 导航页 | 设置窗口左侧导航 → 🔊 分贝仪 | 实时预览（可切样式 / 切换预览底色深浅）、一键校准、全部 23 项设置（常用 10 + 高级 13） |

导航页的三条设计取舍：

- **只在停在该页时占用麦克风**：切到别的设置页立刻释放设备（每 400ms 检查一次面板激活状态），离开本页时预览显示「离开本页时自动释放麦克风」。
- **草稿 + 显式保存**：宿主每写一项设置都会整体重载插件并重新申请麦克风，所以改动先攒在草稿里，点「保存」才一次性提交；页面底部会显示「已改 N 项」。
- **重载后自动切回本页**：插件重载会整块重建导航页、宿主会把用户退回「插件」页，所以把「停在本页」记在 `window` 上，重挂载后自动点回来并提示「已保存」。

预览用的是**草稿值**，所以拖「手动校准偏移」「缩放」「卡片底色」这一类滑条时能立刻看到效果，但此时还没写回配置。

## 原理与校准

```
麦克风 → AnalyserNode.getFloatTimeDomainData → RMS → dBFS = 20·log10(rms)
显示值 = dBFS + 校准偏移
```

Web Audio 只能给出相对满量程的 dBFS，**不是计量级声压读数**。两种校准方式：

- **自动校准**（开关）：进入关灯后先采样 1.6 秒环境底噪，把「安静时的读数」对齐到设定目标值（默认 40 dB）。换教室、换机器开一次就够。
- **手动校准偏移**：读数偏高就调小、偏低就调大，1 档 ≈ 1 dB。

判读标准：

| 模式 | 达标 good | 一般 warn | 超标 bad |
|---|---|---|---|
| 自习 / 安静 | < 阈值 A（默认 55） | 阈值 A–B | > 阈值 B（默认 70） |
| 早读 / 洪亮 | > 阈值 B（默认 70） | 阈值 A–B | < 阈值 A（默认 55） |

阈值判定带 1.5 dB 迟滞，读数在阈值附近抖动时不会来回跳档。

## 9 种样式

`经典 classic`（大数字 + 状态灯）、`极简 minimal`、`圆环 ring`、`光条 bar`（带峰值刻度）、
`胶囊 pill`、`状态词 text`、`弧形表 gauge`、`呼吸灯 pulse`、`波形 wave`（实时声波）。

## 一些实现上的选择

- **关掉了 AGC / 降噪 / 回声消除**（`echoCancellation: false, noiseSuppression: false, autoGainControl: false`）—— 自动增益会把电平拉平，分贝就失真了。
- **不接 `destination`**：只分析不播放，不会回授啸叫。
- **整层不吃鼠标事件**：背景板的「双击退出关灯 / ESC 退出」始终有效。只有显式开启「点按仪表暂停」时，仪表那一小块才会接收点击。
- **颜色跟随背景亮暗**：卡片底色和文字色由宿主的 `dc.theme()` 判断，昼夜切换（或改背景色）时自动换深卡 / 浅卡。
- **文案跟随应用语言**：关灯窗口读 `<html lang>`（`lights-off.js` 会写它），但**设置窗口不会写**（`settings.js` 只替换 `[data-lang]` 的文案），
  所以统一改成「探测宿主自己的文案节点」（中文必含汉字），拿不到才退回 `<html lang>` —— 两个窗口都准，并用 `MutationObserver` 跟着切换。
- **样式表全局生效**，所以所有类名都带 `.dbm-` 前缀；尺寸全部用 `em`，靠卡片基准字号实现整体缩放。

## 已知边界

- 多显示器「所有显示器」铺满时，每个屏幕是一个独立窗口，会各取一次麦克风 —— 同一个设备被多个渲染进程共享，通常正常，但 CPU 会略高。
- 关闭关灯（或改任意设置）时插件会被卸载并停止麦克风；再次进入关灯会重新申请。
- 音量表给的是**相对趋势**。要拿它做题目的量化评分，请先用声级计对一下同一环境下的读数。

## 开发提示

改完 `plugin.json` / `index.js` / `style.css` / `settings.html` 后，在设置界面点该插件的
**重新加载** 即可（改设置项也会自动重载）。用 **导入文件夹…** 选中本目录时迭代最快。
