# Digital Clock / 桌面大时钟

一个美观、高度可定制的桌面时钟应用，基于 **Electron** 构建。支持流畅的数字切换动画、多时区显示、自动日夜颜色切换，以及完全自定义的显示效果。

## 功能特性

- **数字动画切换** — 流畅的数字滚动动画效果，支持速度调节
- **完全自定义** — 文本颜色、背景颜色（支持透明度）、字体、字号、窗口位置
- **日期显示** — 可配置日期位置（时间上方 / 下方）
- **多时区支持** — 最多显示 2 个额外时区
- **自动日夜切换** — 根据当前时间（6:00–18:00）自动切换黑 / 白文本颜色
- **置顶 / 桌面模式** — 选择时钟是否始终显示在所有窗口之上
- **鼠标穿透** — 让整个窗口可点击穿透
- **系统托盘** — 右键菜单进入设置，左键切换显示/隐藏
- **双语界面** — 中文（zh）和英文（en）界面自由切换
- **配置持久化** — 所有设置自动保存至 `config.json`

## 快速开始

```bash
# 安装依赖
npm install

# 启动
npm start

# 构建便携版可执行文件
npm run dist
```

构建产物将位于 `dist/` 目录，为 Windows 便携版应用程序。

## 项目结构

```
├── main.js          # Electron 主进程（窗口、托盘、IPC 通信）
├── preload.js       # 上下文桥接（安全的 IPC 暴露层）
├── index.html       # 时钟主窗口
├── renderer.js      # 时钟渲染、动画、实时更新
├── styles.css       # 时钟样式
├── settings.html    # 设置窗口
├── settings.js      # 设置页面逻辑
├── settings.css     # 设置页面样式
├── config.json      # 用户配置（自动生成）
├── package.json     # 依赖与构建配置
└── LICENSE          # MIT 许可证
```

## 配置说明

所有设置存储在 `%APPDATA%/digital-clock/config.json` 中，可通过设置窗口（右键托盘图标 → 设置）进行调整。

可用设置项：文本颜色、背景颜色（含透明度）、字体、字号、窗口预设位置、是否显示秒、是否显示日期、日期位置、时区显示、图层模式、开机自启动、鼠标穿透、动画速度及语言。

## 技术栈

- **Electron** — 跨平台桌面框架
- **原生 JavaScript** — 无框架依赖，轻量高效
- **CSS 自定义属性** — 通过 CSS 变量实现动态动画时长控制
- **IPC** — 主进程/渲染进程通过 Electron IPC 通信
