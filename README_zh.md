# Digital Clock / 桌面大时钟

一个美观、高度可定制的桌面时钟应用，基于 **Electron** 构建。支持多种数字切换动画、错峰效果、模糊/缩放过渡、多时区显示、自动日夜颜色切换，以及完全自定义的显示效果。

## 功能特性

### 动画系统
- **7 种动画效果** — 上滑翻转、下滑翻转、淡入淡出、缩（旧变小）、放（旧变大）、3D 旋转、无动画
- **错峰数字动画** — 每位数字独立延迟（0–300ms），支持从左到右 / 从右到左方向
- **模糊过渡** — 在上滑/下滑动画中添加模糊效果（可调节持续时间和模糊强度）
- **由小放大滑入** — 数字从较小的比例滑入放大（可调节起始大小）
- **速度调节** — 动画时长 50–1000ms 可调

### 显示自定义
- **文本颜色** — 任意十六进制颜色
- **背景颜色** — 支持 RGBA 颜色与透明度调节
- **字体** — 预设（Arial, Georgia, Microsoft YaHei, Courier New, Inter）或输入自定义字体名称
- **字号** — 40–400px 范围
- **日期显示** — 开关控制，位置可选择时间上方或下方
- **日期/时区文字比例** — 独立滑块调节（时钟字号的 10%–100%）
- **自动日夜切换** — 根据时间（06:00–18:00）自动切换黑白文本颜色

### 时间与时区
- **显示秒** — 开关控制
- **多时区支持** — 最多显示 2 个额外时区，可自定义标签和 UTC 偏移（如"纽约 UTC-5"）

### 窗口与系统
- **6 种位置预设** — 左上、右上、居中、左下、右下、自定义 X/Y 坐标
- **拖拽自动保存** — 直接拖动窗口即可移动，位置自动保存为"自定义"
- **图层模式** — 置顶模式 / 桌面普通模式
- **鼠标穿透** — 让整个窗口可点击穿透
- **自定义托盘菜单** — 右键托盘图标弹出主题化菜单（设置 / 退出）；左键切换显示/隐藏
- **开机自启动** — 随 Windows 自动启动
- **双语界面** — 中文（zh）和英文（en）设置界面自由切换
- **配置持久化** — 所有设置自动保存至 `config.json`

### 闹钟
- **多闹钟管理** — 在设置面板中创建、编辑、删除闹钟
- **自定义名称** — 自动编号，编号空缺自动复用
- **声音选择** — 支持 Beep、Chime、Alarm 三种提示音（Web Audio API），也可选择无声音
- **重复周期（星期选择器）** — 自由勾选星期一至星期日中的任意组合
- **稍后提醒** — 可配置的提醒间隔（时/分/秒），支持无限重试或自定义重试次数
- **内联显示** — 在时钟界面上显示最近的闹钟时间：`! hh:mm !` 表示即将响铃，`? hh:mm ?` 表示等待重试；响铃时每 3 秒与闹钟名称交替显示
- **响铃行为** — 强制显示窗口（可配置）、临时关闭鼠标穿透（可配置）、强制置顶（可配置）、数字红色闪烁（可配置）、单击任意位置关闭；响铃持续时间可配置，结束后进入延时
- **智能跳过** — 7 分钟内的重叠闹钟自动关闭（前一个闹钟无人处理时）
- **重试机制** — 120 秒无人关闭后按稍后提醒间隔重试，可配置重试次数上限
- **重启恢复** — 程序关闭期间错过的闹钟自动顺延到下一周期，启动时弹出系统通知
- **闹钟高级设置**（设置面板可折叠）：
  - 响铃持续最长时间（5–300s 滑条，默认 120s）
  - 闹钟响时闪烁（开关）
  - 闹钟响时自动取消隐藏（开关）
  - 闹钟响时自动关闭鼠标穿透（开关）
  - 闹钟响时自动置顶（开关）

## 快速开始

```bash
# 安装依赖
npm install

# 启动
npm start

# 构建便携版可执行文件
npm run dist
```

构建产物将位于 `dist/` 目录，为 Windows 便携版应用程序。

## 项目结构

```
├── main.js          # Electron 主进程（窗口、托盘、IPC 通信）
├── preload.js       # 上下文桥接（安全的 IPC 暴露层）
├── index.html       # 时钟主窗口
├── renderer.js      # 时钟渲染、动画、实时更新
├── styles.css       # 时钟样式（动画关键帧、模糊/缩放效果）
├── settings.html    # 设置窗口
├── settings.js      # 设置页面逻辑及国际化文案
├── settings.css     # 设置页面样式
├── config.json      # 用户配置（自动生成，位于 %APPDATA%/digital-clock/）
├── package.json     # 依赖与构建配置
├── docs/
│   └── screenshots/ # 应用截图
└── LICENSE          # MIT 许可证
```

## 配置说明

所有设置存储在 `%APPDATA%/digital-clock/config.json` 中，可通过设置窗口（右键托盘图标 → 设置，或左键点击托盘图标再右键）进行调整。

可用设置项：

| 分类 | 设置项 |
|---|---|
| **外观** | 文本颜色、背景颜色（RGBA 含透明度）、字体（预设或自定义）、字号、日期/时区文字比例 |
| **动画** | 动画类型（7 种）、动画时长、错峰延迟及方向、模糊效果（开关/持续/强度）、缩放滑入（开关/起始大小） |
| **时间** | 显示秒、显示日期、显示星期、日期位置（上方/下方） |
| **闹钟** | 多闹钟管理（自定义名称、时间选择、声音选择、星期重复）、可配置稍后提醒（间隔 + 重试次数）、智能跳过、重试机制、内联显示、高级设置（响铃时长、闪烁、自动显示、自动穿透、自动置顶） |
| **时区** | 最多 2 个额外时区，自定义标签与 UTC 偏移 |
| **窗口** | 位置预设（6 种）、自定义 X/Y 坐标、图层模式 |
| **系统** | 开机自启动、鼠标穿透、语言（中文/English） |

## 技术栈

- **Electron** — 跨平台桌面框架
- **原生 JavaScript** — 无框架依赖，轻量高效
- **CSS 自定义属性** — 通过 CSS 变量实现动态动画时长、模糊和缩放控制
- **IPC** — 主进程/渲染进程通过 Electron IPC 通信
- **electron-builder** — Windows 便携版打包
